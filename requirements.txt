# 安装(国内源,避免代理 403):
#   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# torch 用 CPU 版,别拉 CUDA 版:
#   - macOS(Apple Silicon)/ 本地:PyPI 上的 torch 默认即 CPU/MPS 版,直接装。
#   - Linux(Docker python:3.11-slim):PyPI 的 torch Linux 轮子自带 CUDA,体积大。
#     如需强制 CPU 版,单独执行:
#       pip install torch==2.12.0 --index-url https://download.pytorch.org/whl/cpu
#
# 版本说明:本组同时支持 Python 3.11(Docker 目标)与 3.13(本机)。
# 注意:torch 在 Python 3.13 上最低需 2.6.0(2.5.x 无 3.13 wheel),
# 故统一固定到 2.12.0。3.13 已本地实测装通(pytest 7 passed、exp1 出表+图)。
# ⚠️ 3.11(Docker)上 2.12.0 的 wheel 尚未验证,第二步 docker build 会暴露;
#    若 3.11 装不上,降到 2.6.0~2.8.0 区间通常两版本通吃。
